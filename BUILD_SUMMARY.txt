HOW IT WORKS (User Perspective)
═══════════════════════════════════════════════════════════════════════════════

1. USER VISITS APP
   → Lands on welcome screen
   → Clicks "Get Started"

2. SELECT THEME (5 Options)
   FOMO (Red/Orange)          - Urgency & scarcity
   SALES (Gold/Orange)        - High-value offers
   PROMO (Blue/Teal)          - Launch announcements
   SERVICE (Green/Sage)       - Product superiority
   SOCIAL (Purple/Mauve)      - Social proof & testimonials

3. CHOOSE VIDEO FORMAT
   9:16 (Vertical)            - Instagram Reels, TikTok
   1:1 (Square)               - Universal

4. SELECT MUSIC
   Use default track OR upload custom MP3/WAV/OGG
   Auto-trims to video length
   Fade-in/out applied automatically

5. EDIT TEXT
   Auto-generated scenes shown
   Click to edit any text
   Each scene ~1.5 seconds

6. ADD BRANDING
   Upload logo (or use default)
   Edit brand name ("PortfolioHubs" default)
   Edit slogan (Arabic RTL support)
   Set end card duration (1-5s)

7. REVIEW EVERYTHING
   See all settings in readable format
   Click any section to edit
   Download settings as JSON

8. EXPORT VIDEO
   Click "Export Video (MP4)"
   Watch progress bar (0-100%)
   MP4 auto-downloads when complete
   Takes 5-15 seconds on most devices
